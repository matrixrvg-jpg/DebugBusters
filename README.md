# ⚡ Phantom Load Auditor

### Track • Analyze • Eliminate Hidden Energy Waste

---

## 🌍 Problem Statement

Modern households unknowingly waste electricity through **phantom loads** — energy consumed by devices even when they are turned off or idle.

This leads to:

* ⚠️ Higher electricity bills
* 🌫️ Increased carbon emissions
* 🔌 Inefficient energy usage

---

## 💡 Our Solution

**Phantom Load Auditor** is an intelligent web application that:

✅ Identifies hidden energy consumption
✅ Calculates real cost impact
✅ Highlights top energy-wasting devices
✅ Provides actionable recommendations
✅ Simulates savings scenarios

## 🧮 Core Logic

Energy calculations:

* **Active Energy**

  ```
  kWh = (Watt × Hours) / 1000
  ```

* **Phantom Load**

  ```
  5W × (24 - active hours)
  ```

* **Cost**

  ```
  Cost = kWh × ₹8
  ```

* **CO₂ Emission**

  ```
  CO₂ = kWh × 0.82 kg
  ```
